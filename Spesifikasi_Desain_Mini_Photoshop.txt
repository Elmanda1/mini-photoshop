1. DESKRIPSI SISTEM
----------------------------------------------------------------
Mini Photoshop adalah aplikasi pengolahan citra digital berbasis
web. Backend Python + FastAPI menangani semua logika pemrosesan
citra. Frontend React/Next.js sebagai antarmuka interaktif.

Konsep yang diimplementasikan:
- Enhancement, transformasi geometrik, filtering
- Segmentasi, manipulasi warna, kompresi
- Pengenalan objek berbasis CNN (nilai tambah)

----------------------------------------------------------------
2. ARSITEKTUR SISTEM
----------------------------------------------------------------

Stack Teknologi:
  Layer             | Teknologi                  | Keterangan
  ------------------|----------------------------|-------------------
  Backend           | Python + FastAPI            | REST API
  Image Processing  | OpenCV + NumPy + Pillow    | Semua operasi citra
  Machine Learning  | TensorFlow / PyTorch       | CNN recognition
  Frontend          | React/Next.js + Tailwind   | Antarmuka pengguna
  Komunikasi        | REST API (JSON + Base64)   | Transfer gambar

Struktur Folder:
  mini-photoshop/

      │   ├── ToolPanel.jsx
      │   ├── HistogramChart.jsx
      │   └── MLResult.jsx
      └── lib/api.js               # Axios wrapper ke FastAPI

Alur Komunikasi:
  1. User upload gambar di frontend (drag & drop / file picker)
  2. Frontend encode Base64 → kirim ke FastAPI endpoint
  3. Backend proses dengan OpenCV → kembalikan Base64
  4. Frontend decode → tampilkan di panel Before/After
  5. Parameter (slider, dropdown) dikirim sebagai JSON body

3. SPESIFIKASI FITUR SISTEM (11 MODUL)
----------------------------------------------------------------

MODUL 1 — Image Management
  - Load image: JPG, PNG, BMP dari lokal
  - Save image: pilih filename & format output
  - Reset ke gambar awal (original)
  - Panel Before/After berdampingan

MODUL 2 — Image Enhancement
  - Brightness & Contrast Adjustment (slider)
  - Histogram Equalization
  - Sharpening
  - Smoothing (blur)
  Teknis: operasi piksel langsung, histogram stretching, unsharp masking

MODUL 3 — Geometric Transformation
  - Rotate (0–360°)
  - Flip (horizontal / vertikal)
  - Crop (drag area pada canvas)
  - Resize (scaling dengan faktor)
  - Translation (geser posisi)
  Teknis: transformasi matriks affine, interpolasi nearest/bilinear

MODUL 4 — Image Restoration (Noise Reduction)
  - Gaussian Blur
  - Median Filter
  - Noise removal: salt & pepper
  Teknis: spatial filtering, kernel convolution

MODUL 5 — Binary & Edge Processing
  - Thresholding (binary image)
  - Edge Detection: Canny, Sobel, Prewitt, Robert, Laplacian, LoG
  - Morfologi: Erosion, Dilation
  Teknis: operasi piksel biner, kernel structuring element

MODUL 6 — Color Processing
  - RGB → Grayscale
  - Channel splitting (R, G, B)
  - Color adjustment: hue & saturation
  Teknis: transformasi ruang warna BGR→HSV, manipulasi channel array

MODUL 7 — Image Segmentation
  - Threshold-based segmentation
  - Edge-based segmentation
  - Region-based sederhana
  Teknis: clustering sederhana / masking, region extraction

MODUL 8 — Image Compression
  - Save dengan kualitas berbeda (low–high slider)
  - Simulasi kompresi JPEG
  Teknis: Huffman, Aritmetik, LZW, RLE, Kuantisasi

MODUL 9 — Histogram Analysis
  - Histogram grayscale
  - Perbandingan before vs after
  Teknis: distribusi intensitas pixel, Chart.js (frontend)

MODUL 10 — User Interface (GUI)
  - Menu toolbar: File, Edit, Filter, Transform
  - Panel preview before vs after
  - Slider untuk semua parameter
  - Tombol aksi cepat

MODUL 11 — Object Recognition CNN (Nilai Tambah) ⭐
  - Pilih 1 objek: manusia / hewan / kendaraan / dll
  - Model CNN (transfer learning: MobileNetV2 / ResNet)
  - Tampilkan label + confidence score di UI

----------------------------------------------------------------

  -------|-----------------------|--------------------------------

  POST   | /api/image/save       | Download gambar hasil edit
  POST   | /api/enhance          | Brightness, contrast, dll
  POST   | /api/transform        | Rotate, flip, crop, dll
  POST   | /api/filter           | Gaussian, median, noise
  POST   | /api/edge             | Edge detection + morphology
  POST   | /api/color            | Grayscale, channel, hue/sat
  POST   | /api/segment          | Segmentasi
  POST   | /api/compress         | Kompresi JPEG

Wajib Ada (Nilai Utama):

  - Satu file = satu modul → mudah debug
  - Test tiap endpoint via Swagger UI (/docs) sebelum connect FE
  - Untuk CNN gunakan transfer learning (MobileNetV2) → training cepat
  - Kirim gambar ulang tiap request (stateless) atau simpan di session
